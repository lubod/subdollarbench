Reviewed 2026-11-17 at `798eceb` (`Status: ready c650df6`). The gate

required). Two blockers:

- **R90-1 (blocker): a marker left open is never cleared, so every later
  session waits 90 s.** The sidecar writes one marker per call into
  `billed.jsonl.open/` and removes it when the call ends; `wait_idle`
  returns the markers still open at its 90 s deadline and the runner
  only logs them. The directory lives in the run dir, shared by every
  session of the phase, and nothing ever removes a marker whose sidecar
  is gone (`BillingProxy::start` does not clear it). One long call open
  at a session's end (a high-effort generation over 90 s, then
  `docker rm -f` on the sidecar) leaves a marker that makes every later
  session in the phase wait the full 90 s and log it again (about 30
  sessions: about 45 minutes of the 480-minute wall). Fix: after naming
  the still-open markers, move them aside (for example to
  `billed.jsonl.lost/`, kept as evidence), so only this session's calls
  are waited for. Test: `r90_m4_stale_marker_does_not_delay_the_next_session`
  (a marker left by an earlier session; the next session's wait returns
  at once), seen failing.
- **R90-2 (blocker): `src/grading.rs` is a grader path, not plumbing.**
  Its own header says the grading lock and the fast-core pinning exist

  AGENTS.md: a path is grader "if it decides a score". Class it
  `grader` in `scripts/graded-paths.txt` (the others M5 added stay
  plumbing).
