# Round 77: a retried rate limit is not a billing fault

Status: open

Rules: `2026-11-09.46` (unchanged: how the harness classifies a provider error, not what the candidate sees or how it is graded)

## Why

- Ling's `.46` grid (2026-11-10) stopped after 4 phases. Career 0's phase
  1 (`campaign_sdb-sql_openrouter_inclusionai_ling-3.1-flash_20261110_034436_w1`)
  logged one transient rate limit on stderr at 05:13:13 UTC:
  `Retrying (1/10): 429 Provider returned error retry-after-ms=5000
  inclusionai/ling-3.1-flash is temporarily rate-limited upstream.`
  omp retried it on its own and the session went on for 20 more minutes,
  until its budget ran out.
- The stderr reader (`src/sandbox/omp.rs:965`, `classify_billing_error`)
  sets `billing_tripped` on **any** 429, so the cell ended as a harness
  fault ("provider billing/auth/throttle tripped mid-session",
  `src/sandbox/omp.rs:1116`) and the grid wrote STOP. The session-file
  path (`src/sandbox/omp.rs:1395`) treats 429 the same way.
- A 402 (out of credit) or 401 (bad key) must stop the cell (round 63
  R63-3, round 65). A 429 that omp retries and gets past is ordinary
  provider weather; only a 429 that **ends** the session should.

## Items

### F1. A retried 429 doesn't trip the billing fault

- A 429 seen while omp is still retrying (its `Retrying (n/m)` line, with
  n < m) is **transient**: logged, counted (F2), not a fault.
- The fault fires for:
  - any 402 or 401, as today;
  - a 429 that ends the session: omp's retries are exhausted (n = m, or
    the session's final message is the 429 error), or the agent stops
    with the 429 as its last error.
- Both paths (stderr, `src/sandbox/omp.rs:965`, and the session file,
  `src/sandbox/omp.rs:1395`) use the same rule, in one function.

Acceptance:
- [ ] Test `r77_f1_retried_429_is_transient` on the real stderr line
  above: not a fault. Seen failing against `round-77-open`.
- [ ] Test `r77_f1_exhausted_429_trips`: `Retrying (10/10)` then the
  error, or a final 429 error message, trips the fault; 402 and 401 still
  trip on the first line (the existing tests keep passing).

### F2. Rate limits are counted, not hidden
