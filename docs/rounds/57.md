## Why

- **R55-3** (`55.md`, Review): the pre-push hook reads its allowlist
  from the working tree (`allow_file="$root/scripts/secret-scan-fixtures.txt"`,
  `scripts/hooks/pre-push:14`), not from the commit being pushed. A push
  from a checkout with an uncommitted edit to the list uses the edit,
  and a push of a commit that changes the list is judged by the old
  one.
- **R56-3** (`56.md`, Review): the stall's stop reason depends on the
  model's command. The `[STALL]` message holds the command
  (`src/sandbox/omp.rs:1193`), and the stop-reason classifier checks
  `turn limit` and `budget cap` before `[STALL]`
  (`src/sandbox/omp.rs:1082-1086`). A command containing either string
  is labelled `turns` or `dollars`. No production code branches on
  `stop_reason`, so only the label is wrong.
