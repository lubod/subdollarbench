## Why

The TUI captured at 110 columns during the 2-lane smoke (2026-10-31,
operator "put it"):

```
subdollarbench tui · cells ● 2 running · rules 2026-10-19.44 · image — · queue 0 ?help q quit
│1   deepseek-v4.1-flash-1017      ▶····················     0.0/10    $0.0000   —       run t0 32/200       │
│3   deepseek-v4.1-flash-1017      ■■■■■■■··············     10.0/76   $0.2769   36.1    done · ladder end   │
│4   deepseek-v4.1-flash-1017      ■■■■■················     6.0/10    $0.1654   36.3    cancelled           │
│ticket $ 0.0342   campaign $ 0.0000 / 0.50   wall 5/480 m                                                   │
```

- **The points scale changes with the state.** All three rows are
  phase-1 cells. The finished one shows `/76`; the running and cancelled
  ones show `/10`. `max_points` (`src/tui.rs:326`) returns 76 whenever
  the rollup has a `career` block, and the rollup's `max_points`
  otherwise.
- **Campaign spend reads $0 while ticket 0 runs.** The live line prints
  `live.campaign_spent` (`src/tui.rs:514-519`), which counts only
  finished tickets, so it is lower than the ticket line above it.
- **`image —` always.** The header reads `/api/status`'s
  `sandbox_image` (`src/tui.rs:392`), and `StatusResponse` has never
  had that field. This is the R42-7 pattern: a field name the API
  doesn't serve.
- **R54-3** (`54.md`, "After the merge"; operator "55"): the pre-push
  hook refused its own source. F5 is off the round's theme, but it is
  small and ungraded, and round 56 is full.
- **R52-1** (`52.md`, Review): with the engine unreachable,
  `status_field` (`src/tui.rs:375-377`) prints the whole error text, so
  at 80 columns the `?help q quit` hint is cut again (R42-6).

## Items

- A row's points and denominator say the same thing for every state:
  - a career phase (the rollup has `phase`) shows its career's points
    over 76;
  - a cell outside a career shows its own points over its `max_points`.
- A running career phase counts the career's points so far (the chain's
  points plus this phase's).

### F5. The pre-push hook passes its own fixtures (R54-3)

- **What's wrong:** the first push after round 54's merge was refused
  with 4 hits (`54.md`, "After the merge"). Each hit was the hook's own
  `secret_re` line (`scripts/hooks/pre-push:11`) or a planted fixture
  (`scripts/hooks/self-test.sh:54-72`), and none held a real value. The
  operator pushed with `--no-verify`.
  - The pattern also matches 16 other tracked files today (for example
    `src/cost/keys.rs`, `scripts/publish.sh`, `.env.example`). Any
    change to their matching lines trips the hook.
- **Two checks, in this order:**
  - **Real values, everywhere.** An added line holding a value from
    the repo's `.env` is always refused: `OPENROUTER_API_KEY` and
    `SDB_UI_*`, values of 8 characters or more, compared as fixed
    strings, never printed. No allowlist applies to this check.
  - **The pattern, unless the path is allowlisted.** A pattern hit in
    a path listed in `scripts/secret-scan-fixtures.txt` (one path or
    glob per line, comments allowed) is allowed. Any other path is
    refused as now.
- The allowlist starts with the paths that hold fixtures or the
  pattern today. The implementer lists each one in the notes with the
  line that matches. A change to the allowlist file is a commit of its
  own (`R55 F5: …`), so the review sees it.
- **The self-test** pushes a temp repo that holds a copy of
  `scripts/hooks/` and the allowlist:
  - that push is accepted;
  - a line holding the temp repo's `.env` value in an allowlisted path
    is refused, without printing the value;
  - a pattern hit in a path not on the list is refused.

Acceptance:
- [ ] `scripts/hooks/self-test.sh` covers the three cases above; the
  first is seen failing on `7731cda` (the hook refuses its own
  source) — check: the output in the notes.
- [ ] The hook, fed the branch's range directly (no push; the
  implementer never pushes):
  `printf 'refs/heads/round55 %s refs/heads/master %s\n' "$(git rev-parse HEAD)" "$(git rev-parse round-54-merged)" | scripts/hooks/pre-push`
  exits 0. The same command at `7731cda`, with
