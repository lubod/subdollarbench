`Qwen3TTSModel.from_pretrained(..., device_map="cpu",
dtype=torch.float32)`, `create_voice_clone_prompt(ref_audio=, ref_text=)`

voice_clone_prompt=)` per chunk.

## Items

### F1. The reading text and a recording check

`video/voice/reading.txt`: what the operator reads aloud, about 30
seconds of plain narration in the videos' register (no numbers, model
names or abbreviations, so the transcript is unambiguous), followed by
short recording instructions (a quiet room, a normal speaking pace, one
take, WAV or any format `ffmpeg` reads).

`video/voice-ref.sh <recording>`: checks the recording and installs it
as the reference. It refuses a clip shorter than 10 s or longer than
60 s, a silent or clipped one, and a sample rate below 16 kHz; each
refusal names the measured value. A good clip is converted to mono
24 kHz WAV at `~/sdb-video/voice/ref.wav`, with `ref.txt` holding the
reading text's spoken part.

Acceptance:
- [x] A too-short, a silent, a clipped and a low-rate clip are each refused with the measured value; a good clip installs `ref.wav` and `ref.txt` — check: `video/voice-ref.sh --self-test` (clips synthesised with `ffmpeg`, in a temp dir, never in `~/sdb-video/voice/`)
- [x] `ref.txt` equals the spoken part of `video/voice/reading.txt`, with the instructions left out — same self-test

### F2. `video/narrate.py`: a text file becomes narration in the cloned voice

`narrate.py <text-file> <out.mp3>` loads the Base model once, builds the
clone prompt from `ref.wav` and `ref.txt` once, splits the text into
chunks at sentence ends (a chunk holds whole sentences, about 40 words at
most), generates each chunk, and joins them with a short pause between
sentences and a longer one between paragraphs.

- It runs under `nice` with `HF_HOME` set as above, and it stops with a
  clear line when `ref.wav` is missing.
- It is **resumable**: each chunk's audio is cached under
  `~/sdb-video/cache/` by a hash of the chunk text, the reference file
  and the model id, so an interrupted 70-minute render continues and a
  one-sentence edit regenerates one chunk.
- It prints, per run: the chunks generated and reused, the audio
  seconds, the wall seconds and the words per minute.

Acceptance:
- [x] The text splitter keeps whole sentences, respects the word limit, and marks paragraph breaks; abbreviations and decimals ("65.0", "e.g.") don't end a sentence — check: `video/narrate.py --self-test` (no model loaded)
- [x] A second run over the same text generates 0 chunks; changing one sentence regenerates exactly its chunk — same self-test, with a stub synthesiser
- [x] A missing `ref.wav` exits non-zero and names the path and `video/voice-ref.sh` — same self-test

## The test sentences (F4)

1. I gave ten AI models one dollar each. Not to chat, and not to answer trivia. Their job was to build a working SQL database server, from an empty folder, in Go, with no libraries.
2. The best model scored 65.0 points out of 76, and spent $0.99 doing it. The runner-up reached 62.8, and the weakest stopped at 37.
3. Every query goes to the model's server and to SQLite. DeepSeek wrote its server in Go; Claude Haiku and MiMo chose Python. The grader runs SELECT, JOIN and GROUP BY, and compares every row.
4. So what does one dollar actually buy? Less than you'd hope. And, in one case, far more than anyone expected.
5. When the answers differ, even by a single row, in a single query, on a single ticket, the ticket fails, the points are lost, and the model has to decide whether to spend what is left of its dollar fixing the bug or moving on.
6. It passed twenty tickets. Then it broke its own server, and never got it running again.
7. There are three things to watch: the score, the cost, and the test coverage. The full results are at subdollarbench.org.
