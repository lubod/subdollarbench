# Round 68: the bar is required only when grading changes (DECISIONS #26)

Status: draft (operator, 2026-11-08: "future 3")
Opened: <date>, base `round-68-open`
Branch: `round68`
Rules: `2026-10-19.45` (unchanged: which gate a change needs, not how a model is graded)

## Why

- `scripts/graded-paths.txt` decides both the bar key and the gate scope.
  Every graded change moves the key, and `sql-cell.sh` / `grid.sh` /
  `publish.sh` refuse a paid cell until a 20-pass bar (about 7 h) passes
  on it.
- Rounds 65 and 67 changed only harness plumbing, pricing, recording and
  display. Their bars re-ran proofs whose behaviour those changes can't
  touch: the proofs grade the reference server, and call no provider. The
  operator waived 67's bar by hand (`DECISIONS.md` #26).

## Items

### F1. Two classes of graded path

- `scripts/graded-paths.txt` marks which entries are **grader** paths:
  `src/verifier`, `campaigns`, `tasks`, `src/prompts`, `extensions`,
  `src/pipeline.rs`, `src/scoring.rs`, `build.rs`. The rest stay graded
  for the fingerprint and the `--ready` gate: `src/cost`, `src/sandbox`,
  `src/campaign.rs`, `src/report/*`, `Cargo.lock`, `rust-toolchain.toml`.
  - If `src/pipeline.rs` or `src/campaign.rs` mixes grading with
    plumbing, ask under **Spec questions** which side each belongs to.
    Don't split files.
- A new **grader key** (`flake-bar.sh --grader-key`) hashes the grader
  paths only. The bar's record is keyed by it. The full key stays the
  fingerprint.

Acceptance:
- [ ] `scripts/flake-bar.sh --self-test`: a `src/cost` edit keeps the
  grader key and moves the full key; a `src/verifier` edit moves both.

### F2. A cell needs a PASS bar for its grader key

- `sql-cell.sh`, `grid.sh` and `publish.sh` look up
  `flake-<grader-key>.txt`. A change outside the grader paths needs no
  new bar.
- They also require a **$0 rehearsal** record on the full key: a
  rehearsal ledger with 4 ok rows for the exact commit, written by
  `grid.sh --rehearsal`.
- The waiver record of `22b02ab0b9b9` keeps working until the grader
  key replaces it (migration: `flake-<grader-key>.txt` for today's
  grader content is `flake-589e9fd33cd2.txt`'s, as #26 found).

Acceptance:
- [ ] `scripts/sql-cell.sh --self-test`:
  - a full-key change with an unchanged grader key and a rehearsal
    record is allowed;
  - without the rehearsal it is refused;
  - a grader-key change without a bar is refused.
- [ ] AGENTS.md ("Flake bar", "Gates") states the rule. The reviewer
  edits it at the merge.

## Gate

- **Fast** (only `scripts/` and docs). It changes no graded path, apart
  from `scripts/graded-paths.txt` itself, which moves the full key; the
  grader key is unchanged.
