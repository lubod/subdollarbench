### F5. A provider fault is not a score

  tool-call errors (`provider stream ended with an error`, `Upstream

  - its ledger row says so (`stop` = `provider_fault`), and its run

    is never published;

    way the balance preflight holds.

  phases (8-76 %) must trip it; the published models' phases (at most
  0.1 %) must not.
