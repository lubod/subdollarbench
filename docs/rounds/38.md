**Findings:**

- **R38-1 (next): the retry can hold up a boot for minutes.** Each WAL
  attempt may wait out the 5 s busy timeout before it returns busy.
  50 tries can therefore take about 50 × 5.1 s ≈ 4 min before the
  server falls back, where it used to fall back at once. That only
  happens when another process holds `bench.db` locked. Cap the total
  (for example a 10 s deadline). The implementer followed the spec's
  example numbers.
