## Why

The fourth GitHub CI run (`40283735690`, on `cd1a8ef`; `29.md`, "Fourth
run") fixed the UID problem. Two tests still fail, out of 1046. Both
belong to retired campaigns:

- **`live_test_reference_pdf_starts_dual_attached`**
  (`src/sandbox/docker.rs:4135`):

    `pdf-ref` image (`src/sandbox/docker.rs:75-84`).
  - The runner never has that image, so this fails on every run.
- **`test_pipeline_eval_only_proxy_full_ladder_live`:**
  - The failure is "Stage 2: Round-robin across all 3 upstreams -> FAIL
    Uneven spread, hits: [0, 0, 30]".
  - `start_upstream_on` (`src/sandbox/docker.rs`) counts an nginx
    upstream as ready once `docker run -d` returns, without probing it.
  - On the 2-CPU runner, which also pulls nginx first, upstreams 1 and 2
    are likely not serving yet. It passes in the local gates.

**Operator decision, 2026-10-26 (option a):**

  can merge (`34.md`, D3).

  gaps, on `round34`):

  - a pdf test that skips itself when the image is missing.
- Rejected:

  - (c) declare the freeze with CI red.
