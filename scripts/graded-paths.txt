# One graded-path list for scripts/gate.sh (scope), scripts/flake-bar.sh
# (record key) and the ready gate's proof map. A change under any path
# line below moves the full key and the rules fingerprint (where
# applicable).
#
# Each path line starts with its class:
#
#   grader    the bar's live proofs execute it, or it decides a score.
#             A change moves the grader key (flake-bar.sh --grader-key)
#             and needs a bar before a paid cell.
#   plumbing  pricing, recording, display and this list. A change moves
#             the full key only; no new bar.
#
# The classes govern the bar only. A change to what the candidate sees
# (src/sandbox/omp.rs's prompt and arguments, the bench policy,
# tool_normalizer) still falls under the rules-bump policy (AGENTS.md,
# "Rules version"); the full key still covers it, so it still needs the
# --ready gate.
#
# The two data lines at the end are read by scripts/graded-filter.sh, the
# one place the tests.rs rule lives: a file whose basename is exclude-name
# is ignored (test code is not in the release binary), except the exact
# keep path (the file that holds the live proofs).
